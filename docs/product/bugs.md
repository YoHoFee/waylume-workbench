## 状态说明

- **待核实**：仅收到报告或发现可疑现象，尚未确认是缺陷。
- **已确认 / 处理中 / 待验证**：分别表示已复现或有充分证据、正在处理、已有修复但验证未完成。
- **已修复**：记录具体修复及验证范围；若用户验收或真实环境验证尚未完成，应单独注明。
- **无法复现 / 非缺陷 / 重复**：写明依据；重复项关联原编号。保留历史，不直接删除。
